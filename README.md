# Andes Energy — Generador de posts

Web app de una sola página (sin backend, sin build) para generar posts PNG de Instagram
(1080×1080) con la identidad de Andes Energy. Vive en GitHub Pages.

Publicada en: https://domearias.github.io/andes-generador/

- 5 plantillas: portada, texto, con foto, dato, cierre/CTA.
- El texto se vectoriza con opentype.js antes de exportar, así el PNG sale en Outfit.
- Descarga individual o todo el carrusel en .zip.

Archivo único autocontenido (`index.html`): fuentes y librerías van embebidas.
